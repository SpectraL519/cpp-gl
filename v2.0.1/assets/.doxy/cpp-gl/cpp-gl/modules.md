
# Modules


Here is a list of all modules:


* [**Graph Library (GL)**](group__GL.md) _The top-level module defining the general-purpose C++ template graph library._ 
    

    * [**Graph Algorithms**](group__GL-Algorithm.md) _Generic graph algorithms, foundational search templates, and related utilities._ 
        








































    * [**Core Graph Components**](group__GL-Core.md) _Fundamental graph data structures, element descriptors, and configuration tags._ 
        

















































    * [**I/O Utility**](group__GL-IO.md) _I/O stream operations, formatting, and serialization of graph data._ 
        





































    * [**Graph Topologies**](group__GL-Topology.md) _Generators and evaluators for standard structural graph topologies._ 
        











    * [**Traits & Concepts**](group__GL-Traits.md) _Type traits, template constraints, and compile-time metaprogramming utilities._ 
        










    * [**Generic Types**](group__GL-Types.md) _Independent, high-performance data structures and utility types._ 
        







    * [**General Utilities**](group__GL-Util.md) _Practical, domain-agnostic C++ helpers, mathematical functions, and polyfills._ 
        















* [**Hypergraph Library (HGL)**](group__HGL.md) _The top-level module defining the general-purpose C++ template hypergraph library._ 
    

    * [**Hypergraph Algorithms**](group__HGL-Algorithm.md) _Generic hypergraph algorithms, search templates, and related utilities._ 
        


























































    * [**Core Hypergraph Components**](group__HGL-Core.md) _Fundamental hypergraph data structures, element descriptors, and configuration tags._ 
        

















































    * [**I/O Utility**](group__HGL-IO.md) _I/O stream operations, formatting, and serialization of hypergraph data._ 
        




















    * [**Traits & Concepts**](group__HGL-Traits.md) _Type traits, template constraints, and compile-time metaprogramming utilities._ 
        










    * [**Generic Types**](group__HGL-Types.md) _Independent, high-performance data structures and utility types._ 
        








    * [**General Utilities**](group__HGL-Util.md) _Practical, domain-agnostic C++ helpers, mathematical functions, and polyfills._
