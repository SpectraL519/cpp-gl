## Detailed Description


This namespace pulls in practical, domain-agnostic C++ **range** utilities from `gl::util`. Because hypergraphs share the same underlying memory models and algorithmic requirements as standard graphs, they seamlessly reuse the same fundamental C++20 range utilities and helpers.
