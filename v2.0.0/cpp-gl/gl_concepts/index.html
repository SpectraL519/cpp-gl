    gl::traits::c_graph_repr_tag

    Validates if a type is one of the defined graph representation tags.

    Detailed Description

    This concept is used to constrain template parameters that are expected to be specific graph representation tags, ensuring type safety and clear intent in template usage.

    The valid tags include:

    • repr::list_t: Represents a standard adjacency list representation.
    • repr::flat_list_t: Represents a flattened adjacency list representation.
    • repr::matrix_t: Represents a standard adjacency matrix representation.
    • repr::flat_matrix_t: Represents a flattened adjacency matrix representation.

    Template Parameters

    Parameter Description
    T The type to evaluate against the concept.

    Definition

    template<typename T>
concept gl::traits::c_graph_repr_tag = c_one_of<T, repr::list_t, repr::flat_list_t, repr::matrix_t, repr::flat_matrix_t>;

    gl::traits::c_graph_directional_tag

    Validates if a type is a valid graph directional tag.

    Detailed Description

    The valid graph directional tags are directed_t and undirected_t. This concept is used to constrain template parameters that are intended to specify the directionality of a graph, ensuring that only valid tags can be used in such contexts.

    Template Parameters

    Parameter Description
    T The type to evaluate against the concept.

    Definition

    template<typename T>
concept gl::traits::c_graph_directional_tag = c_one_of<T, directed_t, undirected_t>;

    gl::traits::c_binary_color_properties_type

    Requirements for properties that support binary coloring algorithms.

    Detailed Description

    Requires a property type that:

    1. Satisfies c_properties.
    2. Has a nested color_type.
    3. Has a public color member of the color_type type.
    4. Supports construction and comparison with gl::binary_color.

    gl::traits::c_weight_properties_type

    Requirements for properties that support arithmetic weight values.

    Detailed Description

    Requires a property type that:

    1. Satisfies c_properties.
    2. Has a nested weight_type that satisfies c_arithmetic.
    3. Has a public weight member of the weight_type type.

    T The type to evaluate against the concept.
