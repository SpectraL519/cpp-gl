    hgl::traits::c_search_tree

    Validates if a type is a valid hypergraph search tree (a random access range of search_nodes).

    Template Parameters

    Parameter Description
    T The type to evaluate against the concept.

    Definition

    template<typename T>

    and c_instantiation_of<std::ranges::range_value_t<T>, algorithm::search_node>;

    hgl::traits::c_hypergraph_repr_tag

    Validates if a type is one of the defined hypergraph representation tags.

    Detailed Description

    This concept is used to constrain template parameters that are expected to be specific hypergraph representation tags, ensuring type safety and clear intent in template usage.

    The valid tags include:

    • repr::list_t: Represents a standard incidence list representation.
    • repr::flat_list_t: Represents a flattened incidence list representation.
    • repr::matrix_t: Represents a standard incidence matrix representation.
    • repr::flat_matrix_t: Represents a flattened incidence matrix representation.

    Template Parameters

    Parameter Description
    T The type to evaluate against the concept.

    Definition

    template<typename T>
concept hgl::traits::c_hypergraph_repr_tag = c_hypergraph_incidence_list_repr<T> or c_hypergraph_incidence_matrix_repr<T>;

    hgl::traits::c_hypergraph_directional_tag

    Validates if a type is a valid hypergraph directional tag.

    Detailed Description

    The valid hypergraph directional tags are undirected_t and bf_directed_t. This concept is used to constrain template parameters intended to specify the directionality of a hypergraph.

    Template Parameters

    Parameter Description
    T The type to evaluate against the concept.

    Definition

    template<typename T>
concept hgl::traits::c_hypergraph_directional_tag = c_one_of<T, undirected_t, bf_directed_t>;

    Validates if a type is a valid asymmetric hypergraph layout tag.
